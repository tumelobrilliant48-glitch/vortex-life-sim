# Property and housing layer

## Goal
This layer turns the world from a simple village into a world where people own, rent, and build homes and property.

## Included features

- `PropertyOwnership` for owner tracking and sale logic
- `HouseBuildingProgress` for construction progression over days
- `RentSystem` for basic rent payment logic

## Why this matters

This is essential for the life-sim feel because it lets players:
- buy houses
- rent homes
- build property over time
- create realistic living systems
- begin transitioning from village life into town and city economies
