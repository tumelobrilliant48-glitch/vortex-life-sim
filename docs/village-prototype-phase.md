# Village prototype phase

## Goal
Build the first truly playable and believable village layer for VORTEX Life Sim.

## Included features

- village generation script for building blocks, roads, and spawn point
- player HUD for stats and time
- player spawn point generation
- interactable village objects: job marker, shop marker, house marker
- money and purchase flows tied to simple gameplay actions

## Next features to add

1. A proper UI canvas with all stat text fields
2. A player selection screen
3. NPC walking and simple workplace navigation
4. Player-owned home system
5. Vehicle spawning and basic driving
6. Public transport and travel system
7. Crime and police behavior
8. Family and relationship systems

## Rule for expansion

The village must feel alive before adding the next larger layer.
