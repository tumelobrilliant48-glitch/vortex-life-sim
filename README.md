# VORTEX Life Sim — README update

This repository is now moving into the first playable prototype phase.

## Current milestone

The project includes the first layer of infrastructure and now includes the following Phase 1 systems:

- basic player needs decay
- hunger, thirst, hygiene, health reduction logic
- time progression
- NPC schedule simulation
- simple job system with salary
- simple economy manager
- interactable objects for the village prototype

## Prototype vision

The first real game loop is:

- wake up
- eat
- go to work
- earn money
- buy food or household needs
- rest and recover
- continue through the village day cycle

This is the groundwork for the larger world simulation, from villages to cities to countries and eventually space.

## Upcoming next features

- village map and building markers
- house and rent system
- vehicle handling and fuel system
- police and crime simulation
- relationship system
- family and child growth
- school and education progression

We are building in layers, not by trying to create the full 100k-feature world all at once.
